# وب‌سایت دفتر اسناد رسمی شماره ۱۷۶۲ تهران

وب‌سایت رسمی دفترخانه ۱۷۶۲ واقع در جردن تهران — ساخته‌شده با React، TypeScript، Vite و Tailwind CSS.

نشانی اصلی: <https://www.1762daftarasnad.ir>

---

## اجرا

```bash
npm install
npm run dev        # سرور توسعه روی پورت ۳۰۰۰
npm run build      # ساخت نسخه production (نقشه سایت هم ساخته می‌شود)
npm run typecheck  # بررسی نوع‌ها بدون تولید خروجی
npm run sitemap    # ساخت مجدد public/sitemap.xml
npm run icons      # ساخت مجدد آیکون‌ها (نیازمند: npm install --no-save sharp)
```

## معماری

سایت یک اپلیکیشن تک‌صفحه‌ای (SPA) با مسیریابی سمت کلاینت است. **هیچ بک‌اندی وجود
ندارد** — همه فرم‌ها پیام ساختاریافته می‌سازند و آن را در واتساپ دفتر باز می‌کنند.
این تصمیم عمدی است: بدون هزینه سرور، بدون نگهداری، و بدون مسئولیت نگهداری اطلاعات
شخصی مراجعین.

```
src/
├── data/            ← منبع واحد حقیقت؛ محتوا اینجا ویرایش می‌شود، نه در کامپوننت‌ها
│   ├── business.ts    اطلاعات دفتر: تلفن، آدرس، مختصات، ساعات کاری
│   ├── tariffs.ts     جداول تعرفه و تابع محاسبه پلکانی هزینه
│   ├── services.ts    ۱۰ خدمت با مدارک، مراحل، سوالات متداول و کلیدواژه‌ها
│   ├── articles.ts    مقالات مرکز دانش
│   └── reviews.ts     نظرات مراجعین (به Review Schema تبدیل می‌شود)
├── components/      ← کامپوننت‌های مشترک (Seo، ماشین‌حساب، چک‌لیست، فرم‌ها)
├── pages/           ← یک فایل به ازای هر مسیر
└── Layout.tsx       ← پوسته مشترک: هدر، فوتر، دکمه شناور تماس

components/          ← کامپوننت‌های قدیمی صفحه اصلی (Hero, Features, FAQ, Contact) و آیکون‌ها
scripts/             ← ابزارهای زمان بیلد
public/              ← فایل‌های استاتیک: آیکون‌ها، فونت، تصاویر، robots، sitemap
```

### قانون طلایی

هرگز شماره تلفن، آدرس یا ساعت کاری را مستقیماً در JSX ننویسید. همیشه از
`src/data/business.ts` بخوانید. در نسخه‌های قبلی سایت، شماره تلفن در سه جای مختلف
سه مقدار متفاوت داشت — این ناسازگاری مستقیماً به سئوی محلی آسیب می‌زند.

## افزودن محتوا

**خدمت جدید:** یک شیء به آرایه `SERVICES` در `src/data/services.ts` اضافه کنید.
صفحه، مسیر، Schema، ورودی چک‌لیست و مدخل نقشه سایت خودکار ساخته می‌شوند.

**مقاله جدید:** یک شیء به `ARTICLES` در `src/data/articles.ts` اضافه کنید.

**به‌روزرسانی تعرفه‌ها:** تعرفه‌ها **سالانه تغییر می‌کنند**. فقط
`src/data/tariffs.ts` را ویرایش کنید و حتماً `TARIFF_YEAR` و `TARIFF_UPDATED` را
هم به‌روز کنید — این تاریخ به کاربر نمایش داده می‌شود.

---

## سئو

- متاتگ‌ها، canonical و داده ساختاریافته هر صفحه توسط `src/components/Seo.tsx` مدیریت می‌شود.
- Schema سازمان (`Notary` + `Organization`) در `index.html` ثابت است و در همه صفحات مشترک.
- Schema اختصاصی هر صفحه پویا تزریق می‌شود: `Service`، `HowTo`، `FAQPage`، `Article`، `BreadcrumbList`، `Review`.
- `public/sitemap.xml` خودکار در هر بیلد ساخته می‌شود.
- `vercel.json` شامل rewrite برای مسیرهای SPA است تا رفرش صفحات داخلی ۴۰۴ نشود.

### هشدار درباره نظرات

طبق سیاست گوگل، فقط نظرات **واقعی** مجازند. نظرات موجود در
`src/data/reviews.ts` نمونه ساختاری‌اند و باید پیش از انتشار نهایی با بازخوردهای
واقعی مراجعین جایگزین شوند. درج نظر ساختگی می‌تواند به جریمه دستی و حذف کامل
ستاره‌ها از نتایج جستجو منجر شود.

اختیاری و به‌صورت پیش‌فرض غیرفعال. برای فعال‌سازی، فایل `.env` بسازید:

```
VITE_GA_ID=G-XXXXXXXXXX
```

تا وقتی این متغیر تعریف نشده باشد، هیچ اسکریپت ردیابی بارگذاری نمی‌شود.
